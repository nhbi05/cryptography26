# Results

Save the real output of each experiment here as text files, for example:

- `task2_avalanche_output.txt`
- `task3_aes_modes_output.txt`
- `task4_integrity_output.txt`

To save a script's output from the project root:

```bash
python task2_avalanche/avalanche.py > results/task2_avalanche_output.txt
```

Only commit output from actual runs. Note that Task 3 and Task 4 use random keys, IVs and nonces, so their values change on every run. Use the same run for the report, the screenshots and the video.
